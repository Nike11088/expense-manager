# Менеджер расходов

Локальный менеджер расходов на русском языке. Один интерфейс Vue работает в браузере и внутри Android-приложения Capacitor. Валюта — рубли. Сервер, регистрация, аналитика и реклама отсутствуют.

## Возможности

- Обзор месяца: общая сумма, категории и полосы расходов.
- История: раскрывающиеся месяцы и одна кнопка фильтрации в заголовке. Выбранные категории применяются ко всем месяцам сразу. Заголовок месяца показывает сумму по фильтру, раскрытый месяц — также полный итог. Сброс восстанавливает всю историю; переход из категории обзора устанавливает этот же общий фильтр.
- Добавление, редактирование и удаление расходов: сумма, дата, категория, примечание.
- Создание и изменение категорий: 60 позиций SVG, 12 цветов, архивирование и восстановление.
- Светлая и тёмная темы. Нижнее меню: история, обзор, настройки.

Первые шесть категорий создаются автоматически, история начинается пустой. Тестовые записи не включены в поставку. Архивирование категории не удаляет связанные расходы. Название, цвет и иконка категории обновляются также в существующей истории.

## Запуск веб-версии

Требуется Node.js 22.12+; проект проверен на Node.js 24.16.0. На Windows используйте `npm.cmd` и `npx.cmd`.

```powershell
npm.cmd ci
npm.cmd run dev
```

Открыть `http://127.0.0.1:5173`. Для production-сборки:

```powershell
npm.cmd run build
npm.cmd run preview -- --port 4173
```

Содержимое `dist/` можно разместить на статическом HTTPS-хостинге. Используется hash-навигация, перенаправления всех маршрутов на index.html не требуются. Запуск двойным щелчком по index.html не поддерживается. Для удалённого доступа нужен HTTPS; локально допустим localhost.

Веб-версия хранит данные в IndexedDB данного браузера и origin. Android использует SQLite в приватном каталоге приложения. Данные этих версий не синхронизируются. Очистка данных сайта, удаление приложения или очистка его данных удаляет историю; экспорт и резервное копирование в эту версию не входят. Веб-приложение после загрузки работает без сети, но холодный запуск сайта офлайн без предварительного открытия не предусмотрен. APK содержит все ресурсы и запускается офлайн.

## Android APK

Поддержка Android 8.0+ с обновлённым Android System WebView. Для сборки нужны Android SDK 36, JDK 21 и Android Studio. В `scripts/build-android.ps1` заданы пути стандартной установки Android Studio и SDK на Windows; на другом компьютере скорректируйте их.

```powershell
npm.cmd run android:build
```

Скрипт собирает веб-ресурсы, синхронизирует Capacitor, собирает release, выравнивает и подписывает APK, проверяет подпись. Имя файла берётся из версии package.json; текущий результат: `artifacts/expense-manager-1.0.1.apk`.

Ключ создаётся один раз вне проекта: `%USERPROFILE%\.android\expense-manager-release\release.jks`; параметры подписи — рядом в `signing.json`. Доступ к каталогу ограничен текущим пользователем и SYSTEM. Оба файла нужно сохранить для будущих обновлений. Не помещайте их в Git, веб-сборку и публичные архивы. Обновление APK требует того же ключа и увеличения `versionCode` в `android/app/build.gradle`.

Для отладочной сборки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-android.ps1 -DebugBuild
```

Debug и release имеют один applicationId (`app.nikita.expenses`), но разные подписи. На тестовом устройстве переход между ними требует удаления установленной версии. Для обычных обновлений используйте только release с сохранённым ключом.

## Архитектура

- `src/views/` — экраны Vue; `src/components/` — общие элементы.
- `src/store.ts` — Pinia, состояние интерфейса и согласованное обновление после успешной записи.
- `src/domain.ts` — модели, расчёты, даты, форматирование и фильтры.
- `src/storage/repository.ts` — общий асинхронный контракт хранения.
- `src/storage/sqlite.ts` — Android SQLite через `@capacitor-community/sqlite`.
- `src/storage/indexeddb.ts` — браузерный адаптер через `idb`.
- `src/icons.ts` — каталог 60 позиций в порядке присланного образца (12 × 5), включая повторяющиеся символы.

Суммы хранятся в целых копейках, дата — в `YYYY-MM-DD` без UTC-преобразования. Расход имеет стабильный UUID. Обе базы имеют версию схемы 1; новые версии добавляются миграциями, без удаления пользовательских данных. Начальный набор категорий создаётся в транзакции единожды. Pinia не является постоянным хранилищем. При ошибке записи форма остаётся открытой с введёнными данными.

Максимальный отдельный расход — 999 999 999,99 ₽. Примечание — до 500 символов, название категории — до 60. Дубликаты названий без учёта регистра запрещены, включая архивные категории.

## Проверки

```powershell
npm.cmd test
npx.cmd playwright install chromium
npm.cmd run test:e2e
npm.cmd run build
```

Android-тесты требуют запущенного эмулятора или подключённого тестового устройства:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-android.ps1
```

Этот скрипт создаёт отдельную инструментальную debug-сборку с `VITE_NATIVE_TESTS=1`. Она содержит проверку реальной SQLite и не предназначена для передачи пользователям. Release всегда собирайте обычной командой `npm.cmd run android:build`, без этой переменной. Тесты проверяют SQLite, сохранение после открытия базы, редактирование и удаление, поворот экрана, перезагрузку WebView, тему, системные отступы, клавиатуру и навигацию назад. Контрактный тест создаёт отдельную базу в тестовом приложении.

Фактические результаты и ограничения проверки — в `VALIDATION.md`.

## Графика и лицензии

SVG-пиктограммы подобраны из Material Design Icons / Pictogrammers по 60 позициям пользовательского скриншота. Сохранены порядок, повторы, назначение и стиль. Это SVG-аналоги по визуальному образцу, не извлечённые из исходного APK ресурсы; попиксельная идентичность оригиналу не заявляется. Шрифт Roboto включён локально, загрузки с внешних серверов нет.

Уведомления о лицензиях поставляются вместе с приложением: `public/licenses/pictogrammers.txt`, `public/licenses/roboto.txt`. Приложение имеет собственный идентификатор и иконку запуска.

## Пока не входит в версию

Синхронизация, облако, аккаунты, экспорт/импорт, восстановление из оригинального Expense Manager, доходы, бюджеты, регулярные платежи, виджеты, калькулятор выражений и публикация на хостинге.
